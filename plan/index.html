7/22(수) ~ 8/14(금)

이번 여름 자습은 "내가 세운 계획이 나를 만든다"를 원칙으로, 아이가 직접 계획을 세우고 스스로 지키는 훈련에 초점을 둡니다. 모든 계획과 실행 기록은 지수학 자습 플래너 앱에 남고, 선생님의 확인·코멘트와 부모님의 매일 컨펌이 함께 이루어집니다.

① 자습 플래너 앱 사용법

hajun190130-sys.github.io/GMATH/plan/
휴대폰에서 접속 → 홈 화면에 추가하면 앱처럼 사용됩니다. 첫 로그인 시 본인 이름을 누르고 새 PIN을 등록하면 그 번호가 계속 사용됩니다.
STEP 1
🎯 여름 전체 목표
국어·영어·수학·과학(물화생지)·사회 과목별로 이번 여름에 끝낼 것을 [여름계획] 탭에 작성
STEP 2
📆 주간 계획
전체 목표를 주 단위로 쪼개어 작성. 매주 화요일까지 다음 주 계획 제출 — 첫 제출은 7/21(화)까지 전체 목표 + 1주차 계획
STEP 3
📋 일간 계획
매일 아침 자습 시작 전 [오늘] 탭에 그날 계획 작성·저장 (저장 = 제출)

② 하루 운영 루틴

아침 · 자습 전
학생
오늘의 계획 작성·저장 → 제출 시각 자동 기록 (전날 미완료 숙제는 이 시간까지 해와서 선생님 확인)
오전 중
부모님
앱 학부모 화면에서 아이 계획을 읽고 "오전 컨펌" 버튼 클릭 — 확인 시각이 아이·선생님 화면에 표시됩니다
오후 2시
학생
🕑 중간보고 버튼 — 현재까지의 완료 개수가 시각과 함께 기록
저녁 7시
학생
🌙 마감보고 버튼 — 하루 최종 완성도 기록 및 자기평가(별점·공부시간)
귀가 후
숙제
그날 완료하지 못한 계획은 집에서 숙제로 완성 → 다음날 아침 자습 전 선생님이 확인(해옴 ✓ / 안 해옴 ❌)하며 결과가 부모님 화면에도 보입니다

③ 학부모 컨펌 기능 안내

앱 첫 화면 아래 "학부모 관찰"에서 자녀 이름 선택 → 처음 입력하는 번호가 학부모 PIN으로 등록됩니다. 화면에서 오늘 계획·완료 현황·공부시간·선생님 코멘트·최근 14일 기록을 보실 수 있고, 매일 오전 "오늘 계획을 읽었습니다 (오전 컨펌)" 버튼을 눌러 주시면 됩니다. 부모님의 매일 확인이 아이에게는 가장 큰 동력이 됩니다.

④ 여름 자습 규칙

주간 계획은 매주 화요일까지 앱에 제출합니다. 미제출 시 수요일 자습 시작 전 완성 후 입장합니다.
일간 계획은 매일 아침 자습 시작 전 제출이 원칙입니다. 아침 제출 시각이 앱에 그대로 남습니다.
계획이 지나치게 적거나 부실한 경우 선생님 수정안이 계획 바로 아래에 제시되며, 학생은 수정안을 반영해 다시 제출합니다.
2시 중간보고와 7시 마감보고는 본인이 직접 버튼을 눌러 기록합니다.
당일 미완료 항목은 다음날 아침까지 가정 숙제이며, 아침에 선생님이 확인합니다.
자습 중 휴대폰은 계획 확인·보고 용도로만 사용합니다.
